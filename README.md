# IdeaPilot 🚀

> Turn your ideas into actionable AI-generated project plans.

IdeaPilot uses **Gemini AI** to transform a raw idea description into a structured plan — including a summary, recommended tech stack, 4–6 implementation steps, difficulty assessment, and potential challenges.

---

## ⚠️ Demo Disclaimer

Plans are generated by Gemini AI and may contain inaccuracies. Always verify recommendations with domain experts.

This prototype has **no authentication** — all saved plans are shared demo data visible to anyone with the URL.

## Local Development Setup

### Prerequisites

- Node.js 18+
- [pnpm](https://pnpm.io/) (`npm install -g pnpm`)
- A [Supabase](https://supabase.com) project
- A [Google AI Studio](https://aistudio.google.com/) API key

### 1. Run the Database Migration

In your Supabase dashboard, open the **SQL Editor** and run the contents of:

```
supabase/migrations/001_initial_schema.sql
```

### 2. Configure the Backend

```bash
cd server
cp .env.example .env
```

Edit `server/.env`:

```env
PORT=5000
NODE_ENV=development
CLIENT_URL=http://localhost:5173
GEMINI_API_KEY=your_gemini_api_key_here
SUPABASE_URL=https://your-project.supabase.co
SUPABASE_SERVICE_ROLE_KEY=your_service_role_key_here
```

> **Security:** The `SUPABASE_SERVICE_ROLE_KEY` is server-only. Never expose it to the browser.

### 3. Configure the Frontend

```bash
cd client
cp .env.example .env
```

The default `client/.env` points to localhost:

```env
VITE_API_BASE_URL=http://localhost:5000
```

### 4. Install Dependencies & Start

**Terminal 1 — Backend:**

```bash
cd server
pnpm install
pnpm dev
```

Server starts at `http://localhost:5000`.

**Terminal 2 — Frontend:**

```bash
cd client
pnpm install
pnpm dev
```

Frontend starts at `http://localhost:5173`.

## API Reference

| Method   | Endpoint          | Description                                |
|----------|-------------------|--------------------------------------------|
| `GET`    | `/api/health`     | Health check                               |
| `POST`   | `/api/plans`      | Validate input → call Gemini → save → return |
| `GET`    | `/api/plans`      | Return 50 most recent plans                |
| `GET`    | `/api/plans/:id`  | Return a single plan                       |
| `DELETE` | `/api/plans/:id`  | Delete a plan                              |

### Rate Limiting

The `POST /api/plans` endpoint is rate-limited to **5 requests per minute per IP** to prevent API abuse.

## Deployment

### Backend → Render

1. Push your code to GitHub.
2. Create a new **Web Service** on [Render](https://render.com).
3. Set **Root Directory** to `server`.
4. Set **Build Command**: `pnpm install && pnpm build`
5. Set **Start Command**: `node dist/index.js`
6. Add environment variables in Render's dashboard:
   - `NODE_ENV=production`
   - `PORT=10000` (Render assigns its own port via `PORT`)
   - `CLIENT_URL=https://your-vercel-app.vercel.app`
   - `GEMINI_API_KEY=...`
   - `SUPABASE_URL=...`
   - `SUPABASE_SERVICE_ROLE_KEY=...`
7. Deploy. Copy the Render service URL (e.g., `https://ideapilot-api.onrender.com`).

### Frontend → Vercel

1. Import the repo in [Vercel](https://vercel.com).
2. Set **Root Directory** to `client`.
3. Set **Framework Preset** to `Vite`.
4. Add environment variable:
   - `VITE_API_BASE_URL=https://ideapilot-api.onrender.com`
5. Deploy.

> **CORS:** Update `CLIENT_URL` on Render to match your Vercel deployment URL.
